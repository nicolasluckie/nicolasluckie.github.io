My Story

Building things that matter, one system at a time.

I'm a full-stack engineer with 10+ years of experience, specializing in custom MCP server development, enterprise Java architecture, and QE/test automation strategy.

My path here wasn't conventional. Before enterprise software, I spent five years as a funeral director's assistant, where I designed and built the Funeral Service Information System, a mobile-first LAMP-stack CMS that streamlined overnight dispatch operations. That experience taught me to build practical software for people who need it to just work, regardless of domain.

Since 2023, I've worked at RBC, currently as a Senior Software Development Engineer architecting Java developer platforms and MCP servers that connect AI agents to enterprise systems. Outside of work, I run self-hosted AI and infrastructure pipelines in my personal homelab.
